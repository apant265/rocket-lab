# Rocket Lab v0.1.1 — Windows engineering preview

Updates the analysis views and fixes stage separation and transition geometry.

- 2D and 3D views share computed CFD fields, thermal/stress mappings, color scales and wall-layer choices. Vehicle fields use smooth colored triangles; the 3D CFD view also displays the computed planar slice.
- Standard, Fine and Ultra thermal/stress detail increases. Ultra thermal uses 256 axial plus 64 fin cells per stage and a maximum diffusion step of 0.001 s; Ultra fin stress uses 1024 integration divisions.
- Stage separation keeps the sections aligned at their physical joints, including camera tracking and parachute attachments. Exact separation frames support forward and backward playback.
- Front transitions replace the leading cylinder with a round conical taper in the builder, Blender exports, fallback model and CFD profile. The default Kate and Anvil rocket includes both reducers; thermal sections use their wall material and sloped area.
- Blender export failures now stop the build. Windows long-path handling is corrected for GLB exports.

Download `rocket-lab-v0.1.1-windows-x64.zip`, extract the entire folder and double-click `Launch.cmd`. Rust is not required. The bundle includes the updated three-stage desert study with a 5 lb Kate and Anvil payload and rebuilt Blender models. Optional model rebuilding needs Blender; external analysis needs Docker Desktop and Python.

Validation includes 144 passing tests, Clippy with warnings denied, native GPU analysis on an RTX 3060 Ti and headless Blender export checks. The bundle includes numerical/UI evidence and `SHA256SUMS.txt` verifies the download.

This remains an engineering preview. Built-in CFD is planar perfect-gas inviscid Euler with a Cartesian numerical wall; thermal has two through-wall finite volumes, and built-in stress uses CPU beam/shell screening. The 3D views project these computed fields onto geometry. Measured-flight/RASAero validation remains unresolved.
