# Rocket Lab v0.1.2 — Builder and file exchange preview

This release adds editable rocket files, model import/export and improved part attachment, plus a visible flight-regime indicator.

- **File → New rocket / Open rocket / Save / Save as** creates named single-stage designs and opens or saves Rocket Lab JSON files. Ctrl+N, Ctrl+O, Ctrl+S and Ctrl+Shift+S are supported. Changed designs prompt to save before switching; failed loads leave the current design intact.
- Drag parts into the 3D editor and click them for properties. Tubes snap end-to-end. Transitions are ordinary tapered sections with independent fore/aft diameters. Inner tubes and centering rings retain parent attachments; rings can fit the body bore and motor tube automatically.
- Select motors from inner-tube mount properties, filtered by bore and available length. Motor position and preview follow the mount.
- Import/export STL and OBJ, STEP/IGES/BREP/FreeCAD files, and Blender-supported GLB/glTF/BLEND/PLY/FBX geometry. Imported triangles are embedded in the saved rocket. Export the whole vehicle, a stage or a selected part, including structural internals.
- Simulation shows **Subsonic, Transonic, Supersonic or Hypersonic**, Mach, stage and timestamp in the viewport and telemetry panel. The indicator follows forward/backward playback and a selected detached stage.

Download **rocket-lab-v0.1.2-windows-x64.zip**, extract the entire folder and run **Launch.cmd**. It opens in Build. Rust is not required. Checksums are in **SHA256SUMS.txt**.

Blender is needed to evaluate changed designs and convert scene formats. STEP/IGES/BREP/FCStd exchange requires FreeCADCmd. Proprietary CAD projects should be exported to STEP from their authoring application. CAD export creates faceted shells/solids; it does not reconstruct parametric feature history. See [file exchange](https://github.com/apant265/rocket-lab/blob/v0.1.2/docs/model-exchange.md).

Validation includes the full Rust test suite, Clippy with warnings denied, eleven geometry-format round trips, exported internal-component geometry and RTX 3060 Ti flow/thermal execution. The hardware thermal check matched the CPU within 0.1 K. Detailed logs are included in the bundle.

This remains an engineering preview with the existing solver scope: built-in CFD is planar inviscid Euler, and displayed 3D fields map the computed analysis onto geometry. Measured-flight/RASAero validation remains unresolved. See [analysis scope](https://github.com/apant265/rocket-lab/blob/v0.1.2/docs/timestamp-analysis.md).
